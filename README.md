# QQ Pet — 桌面陪伴宠物

一个基于 Live2D 的 Windows 桌面宠物，仿 QQ 宠物体验。住在你桌面上，感知你的工作状态，陪你专注，也陪你摸鱼。

## 功能特性

### 桌面悬浮
- 无边框透明窗口，常驻桌面
- 可拖拽到屏幕任意位置，自动记忆位置
- 置顶开关（右键菜单）
- 开机自启（右键菜单，默认关闭）

### Live2D 互动
- Hiyori 模型（Cubism 4），待机呼吸/眨眼动画
- 眼睛跟随鼠标（全局，鼠标在屏幕任何位置都有效）
- 点头部 → 摸头反应（开心享受）
- 点身体 → 被戳反应（害羞/吓一跳）
- 拖拽移动窗口

### 状态感知
- 每 2 秒采样前台窗口，判断当前状态：
  - **专注中**：IDE / 文档 / 设计软件等
  - **工作插曲**：切到浏览器等，10 分钟缓冲期
  - **摸鱼中**：非专注应用持续超过阈值
  - **离开中**：鼠标键盘空闲 5 分钟
- 状态变化时宠物主动说话

### 里程碑提醒
- 专注 25 分钟 → 加油打气
- 专注 50 分钟 → 提醒休息
- 深夜使用（>23:00）→ 关心提醒
- 离开回来 → 迎接

### 养成系统
- 饱食度 / 心情 / 清洁度 随时间衰减
- 在线时长累计经验，每 600 经验升一级
- 右键喂食 / 洗澡恢复数值
- 低状态（<20）时自动显示状态栏并提醒
- 数据本地持久化，重启不丢失

### 随机互动
- 每 30-60 分钟随机闲聊一句
- 点击宠物有不同台词反应

## 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron 44 |
| 构建工具 | electron-vite |
| 前端 | Vue 3 + TypeScript |
| Live2D 渲染 | pixi-live2d-display + pixi.js 6 |
| 状态采集 | active-win |
| 本地存储 | electron-store + localStorage |

## 项目结构

```
src/
├── main/               # 主进程
│   ├── index.ts        # 窗口创建、右键菜单、IPC、鼠标位置轮询
│   └── status-monitor.ts  # 前台窗口采样 + 状态机 + 里程碑
├── preload/
│   └── index.ts        # IPC 桥接
└── renderer/
    ├── index.html
    └── src/
        ├── App.vue          # 气泡、状态监听、养成、右键菜单响应
        ├── main.ts
        ├── pet-stats.ts     # 数值系统（localStorage 持久化）
        └── components/
            └── PetCanvas.vue # PIXI + Live2D 渲染、点击/拖拽/眼睛跟随
```
